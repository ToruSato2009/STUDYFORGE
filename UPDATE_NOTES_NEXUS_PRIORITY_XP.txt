STUDYFORGE V2 — NEXUS & PRIORITY XP UPDATE

- Renamed the StudyBot companion identity to NEXUS in the task-completion victory popup.
- Added the existing StudyBot artwork to the victory popup; no new character artwork was generated.
- XP rewards now use task difficulty, task duration, and the saved subject priority order.
- Priority multipliers for the first five ranked subjects: 1.30x, 1.15x, 1.00x, 0.90x, 0.80x. Additional ranked subjects use 0.75x. If priorities are not configured, no priority multiplier is applied.
- Duration multiplier is sqrt(minutes / 25), clamped between 0.60x and 2.50x.
- The XP preview updates when difficulty, subject, or duration changes.
- XP is calculated and recorded at task completion. Later priority changes do not rewrite previously earned XP.

Existing planner, daily topics, priority allocation, and task redistribution code retained from the supplied working build.
